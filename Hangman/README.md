#  Hangman Game

A simple text-based Hangman game built using Python.

## Features
- Random word selection
- 5 predefined words
- 6 incorrect guess chances
- Letter-by-letter guessing
- Console-based gameplay

## Concepts Used
- Python Lists
- Strings
- Random module
- While Loop
- If-Else Statements
- User Input
