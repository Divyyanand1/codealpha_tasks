# 📈 Stock Portfolio Calculator

A simple Python-based **Stock Portfolio Calculator** that allows users to enter stock names, specify quantities, calculate the investment for each stock, and calculate the total investment.

## 📌 About

This project is built using Python fundamentals such as **dictionaries, loops, conditions, user input, and file handling**.

The program uses predefined stock prices and calculates the total amount invested based on the stocks and quantities entered by the user.

## ✨ Features

* Enter stock names
* Enter the quantity of stocks
* Calculate investment for each stock
* Calculate total investment
* Validate stock names
* Save the portfolio details to a text file
* Use `DONE` to finish the portfolio

## 🛠️ Technologies Used

* Python
* Dictionary
* While Loop
* Conditional Statements
* File Handling

```bash

```

### 2. Open the project folder

```bash

```

### 3. Run the Python program

```bash
python main.py
```

## 💻 Example

```text
Enter The Stock Name: AAPL
Enter The Quantity: 5
price: 900

Enter The Stock Name: MSFT
Enter The Quantity: 2
price: 800

Enter The Stock Name: DONE

1700
Portfolio Done!!
```

The total investment is also saved in `Portfolio.txt`.
